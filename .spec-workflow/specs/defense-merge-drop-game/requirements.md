# 需求文档（Requirements）

## 1. 功能概述

本项目为一个纯前端、单机运行的掉落合成游戏。玩家通过在容器中投放并合成武器装备，逐步从低级装备进化到高等级重型装备。

- 核心玩法参考“大西瓜类掉落合成”机制，但主题改为“国防装备进化”。
- 核心目标是尽可能合成更高等级装备并提升“国防值”（替代传统积分）。
- 采用“当前国防值 + 历史最高国防值”双显示与本地持久化模式，记录方式参考现有 `2048` 项目的分数记录体验。

## 2. 产品目标

- 提供轻量、可直接在浏览器打开游玩的休闲游戏。
- 通过装备进化主题带来区别于水果合成的创意体验。
- 在“容易上手 + 有成长空间”之间保持中等难度。

## 3. 设计边界与约束

- 仅前端实现，不依赖后端服务。
- 支持桌面端与移动端浏览器（含触控操作）。
- 所有游戏状态（例如最高国防值）保存在浏览器本地存储中。

## 4. 核心玩法设定（需求输入）

### 4.1 合成等级建议

结合此类掉落合成游戏的常见节奏（如 Suika 类游戏常见约 11 个主要合成层级），为保证“中等难度”，本项目建议：

- 默认使用 **12 个装备等级**（可配置），兼顾可达成性与后期挑战。
- 可接受范围：11~13 级；超出该范围会显著改变难度。

建议默认装备链（示例，可在设计阶段微调命名）：

1. 木棍
2. 小刀
3. 短剑
4. 长剑
5. 盾牌战具
6. 火枪
7. 步枪
8. 机枪
9. 火箭筒
10. 坦克
11. 战斗机
12. 核武器

### 4.2 尺寸成长规则

- 等级越高，装备碰撞体积越大。
- 同级装备碰撞后触发合成，生成下一级装备。
- 高级装备更占空间，形成后期空间管理压力。

### 4.3 国防值规则

- 每次发生有效合成时增加国防值。
- 越高等级的合成，获得的国防值越高。
- 显示“当前国防值”与“历史最高国防值”。
- 历史最高国防值在本地持久化，刷新页面后仍可读取。

## 5. 用户故事与 EARS 验收标准

### US-01 新手开局与投放体验

作为玩家，我希望开局即可快速开始投放低级装备，以便迅速理解玩法。

- **EARS-01（事件驱动）**：当玩家点击/触控投放时，系统应在容器顶部生成并释放当前待投放装备。
- **EARS-02（状态驱动）**：当游戏处于进行中状态时，系统应持续允许玩家进行下一次投放。
- **EARS-03（异常约束）**：当游戏结束时，系统不应再接受新的投放输入。

### US-02 合成反馈

作为玩家，我希望同级装备相撞时能明确合成为更高等级，以便建立成长成就感。

- **EARS-04（事件驱动）**：当两个同等级装备发生有效碰撞时，系统应移除原对象并生成下一等级装备。
- **EARS-05（普适约束）**：系统应仅允许“同等级 + 有效碰撞”触发合成。
- **EARS-06（质量约束）**：合成发生时系统应提供可感知反馈（至少包含视觉反馈）。

### US-03 难度递进

作为玩家，我希望高等级装备更占空间，让后期更具策略性。

- **EARS-07（普适约束）**：系统应保证装备等级越高，其占用空间越大。
- **EARS-08（状态驱动）**：当场内高等级装备增多时，系统应自然提高可用空间管理难度。

### US-04 国防值与最高记录

作为玩家，我希望看到每次合成的成长收益，并保留历史最佳成绩。

- **EARS-09（事件驱动）**：当发生有效合成时，系统应按合成等级增加国防值。
- **EARS-10（普适约束）**：系统应始终显示当前国防值与历史最高国防值。
- **EARS-11（状态驱动）**：当当前国防值超过历史最高值时，系统应立即刷新并保存最高记录。
- **EARS-12（异常约束）**：当本地存储不可用时，系统应保持游戏可玩，并优雅降级为仅会话内记录。

### US-05 结算与重开

作为玩家，我希望在失败后快速重开，并保留历史最高记录继续挑战。

- **EARS-13（事件驱动）**：当达到失败条件（容器溢出）时，系统应进入游戏结束状态并展示结算提示。
- **EARS-14（事件驱动）**：当玩家点击“新游戏”时，系统应重置局内状态与当前国防值。
- **EARS-15（普适约束）**：开始新游戏时，系统不应清除历史最高国防值。

## 6. 非功能需求

- 游戏在主流现代浏览器可运行（Chrome/Edge/Safari 的近两年版本）。
- 操作响应流畅；常规设备上应保持可接受帧率（目标 50~60 FPS）。
- 页面首次可交互时间应尽量短（目标 < 3 秒，静态部署环境）。
- UI 需适配移动端竖屏和桌面端常见分辨率。

## 7. 成功指标（验收口径）

- 玩家可从“木棍”开始持续合成到高等级装备。
- 默认 12 级体系下，体验难度主观评估为中等（非极易/非极难）。
- 国防值系统完整可用：增加、显示、最高值更新、刷新后保留。
- 游戏结束与重开流程稳定，不影响历史最高记录。

## 8. 待设计阶段确认项

- 各等级装备的最终命名与视觉风格。
- 国防值具体计算公式（例如线性、指数或混合加权）。
- 失败判定阈值的细节（顶部警戒线触发策略）。
- 是否加入“下一件预览”“轻微辅助道具”等可选机制（默认不做）。
